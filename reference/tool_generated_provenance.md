# Tool generated provenance

Create a
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object that indicates data were generated with the tool.

## Usage

``` r
tool_generated_provenance()
```

## Value

A
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object
