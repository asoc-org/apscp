# Contrast provenance

Create a
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object that indicates data were generated by contrasting two
[`new_solution()`](https://asoc-org.github.io/apscp/reference/new_solution.md)
objects.

## Usage

``` r
contrast_provenance(name1, name2)
```

## Arguments

- name1:

  `character` value indicating the name of a solution.

- name2:

  `character` value indicating the name of a solution.

## Value

A
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object.
