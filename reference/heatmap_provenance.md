# Heat map provenance

Create a
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object that indicates data were generated by comparing multiple
solutions.

## Usage

``` r
heatmap_provenance(zone, names)
```

## Arguments

- zone:

  `character` value indicating the zone name used to generate the heat
  map.

- names:

  `character` vector with the names of the solutions used to generate
  the heat map.

## Value

A
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object.
