# Simulate targets

Simulate a set of zone target values for a feature.

## Usage

``` r
simulate_feature_zone_targets(x, n)
```

## Arguments

- x:

  \`numeric\` vector with options for targets. Note that \`x\` must
  range betweeen 0 and 1.

- n:

  \`integer\` number of zones.

## Value

A \`numeric\` vector with a value for each zone.
