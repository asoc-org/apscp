# Convert \`JsDataFrameList\` object to list object.

Convert a JavaScript list of data frames object to a \`list\` object.

## Usage

``` r
# S3 method for class 'JsDataFrameList'
as.list(x, ...)
```

## Arguments

- x:

  \`list\` object.

- ...:

  Not used.

## Value

A \`list\` of \`data.frame\` objects.
