# Clear layer

Clear an object as a layer from a mapgl object.

## Usage

``` r
mapgl_clear_layer(map, x)
```

## Arguments

- map:

  A map object created by the `mapboxgl` or `maplibre` function.

- x:

  \[new_tile()\] object.

## Details

Layers are cleared with \[mapgl::clear_layer()\].
