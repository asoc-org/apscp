# Add external resources to a Shiny application

This function is used to add external resources to a Shiny application.

## Usage

``` r
apscp_add_external_resources()
```

## Value

A `shiny.tag` object.

## Details

This function adds JavaScript and CSS files for the
[`mapper()`](https://asoc-org.github.io/apscp/reference/mapper.md),
[`solver()`](https://asoc-org.github.io/apscp/reference/solver.md),
[`summarizer()`](https://asoc-org.github.io/apscp/reference/summarizer.md),
[`sidebar_pane()`](https://asoc-org.github.io/apscp/reference/sidebar_pane.md),
and
[`sidebar_tabs()`](https://asoc-org.github.io/apscp/reference/sidebar_tabs.md).
