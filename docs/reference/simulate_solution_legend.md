# Simulate solution legend

Simulate a legend for solution data.

## Usage

``` r
simulate_solution_legend()
```

## Value

A
[`new_categorical_legend()`](https://asoc-org.github.io/apscp/reference/new_categorical_legend.md)
object.

## Details

Note that simulation functions are intended to help faciliate package
testing and should not be used for any research purposes.
