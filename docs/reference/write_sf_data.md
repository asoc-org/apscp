# Write sf data to zip file

Write sf data to zip file

## Usage

``` r
write_sf_data(x, path)
```

## Arguments

- x:

  \[sf::st_sf()\] object.

- path:

  \`character\` file path.

## Value

An invisible \`TRUE\`.
