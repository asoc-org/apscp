# Simulate provenance

Simulate a provenance information.

## Usage

``` r
simulate_provenance()
```

## Value

A
[`new_provenance()`](https://asoc-org.github.io/apscp/reference/new_provenance.md)
object.

## Details

Note that simulation functions are intended to help faciliate package
testing and should not be used for any research purposes.
