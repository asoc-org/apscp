# Start tile server

Start a tile server for a project.

## Usage

``` r
start_tile_server(x, dir = NULL, verbose = TRUE)
```

## Arguments

- x:

  \[new_project()\] object.

- dir:

  \`character\` value for tile server directory. Defaults to \`NULL\`
  indicating a temporary directory.

- verbose:

  \`logical\` value indicating if information about the tile server
  should be displayed? Defaults to \`TRUE\`.

## Value

An invisible \`TRUE\` indicating success.
