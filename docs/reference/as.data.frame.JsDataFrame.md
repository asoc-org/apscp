# Convert \`JsDataFrame\` object to data.frame

Convert a JavaScript data frame object to a \`data.frame\` object.

## Usage

``` r
# S3 method for class 'JsDataFrame'
as.data.frame(x, ...)
```

## Arguments

- x:

  \`list\` object.

- ...:

  Not used.

## Value

A \`data.frame\` object.
