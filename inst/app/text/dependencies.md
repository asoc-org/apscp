This application was built using the [Shiny web application framework](https://shiny.rstudio.com/) for the [R statistical computing environment](https://www.r-project.org/). It uses the [prioritizr R package](https://prioritizr.net/) and the [CBC (Coin-OR branch and cut) ](https://www.coin-or.org/Cbc/) and [Gurobi](https://www.gurobi.com/) optimization software to generate solutions. It also uses the [DataTables](https://datatables.net/), [D3](https://d3js.org/), [Mapbox GL JS](https://docs.mapbox.com/mapbox-gl-js/), [noUiSlider](https://refreshless.com/nouislider/), [SortableJS](https://sortablejs.github.io/Sortable/), modified version of the [sidebar-v2](https://github.com/Turbo87/sidebar-v2) Leaflet plugin, and [Tom Select](https://tom-select.js.org/) JavaScript libraries.
